# apps/dashboard

Internal Bullet Digital Media operations dashboard. Single source of truth for
every signed client's onboarding state, asset checklist, and per-action health.

This package is currently a scaffold (S1-01). The Next.js App Router setup,
shadcn/ui components, dark-mode default, role-based route groups, and
TanStack Query polling land in S1-16 onwards.

## Run

From the repo root:

```bash
pnpm install
pnpm --filter @bullet/dashboard typecheck
```
